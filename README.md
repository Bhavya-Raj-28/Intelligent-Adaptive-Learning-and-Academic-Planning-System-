# AI Learning System

An AI-powered personalized learning platform designed to help students with personalized learning, study planning, quizzes, progress tracking, and AI-assisted tutoring.

## Features

- Student registration and login
- JWT-based authentication
- Personalized dashboard
- AI Tutor using Gemini API
- Study planning
- Quiz functionality
- Progress tracking
- Personalized learning recommendations

## Technologies Used

### Frontend
- React
- Vite
- JavaScript
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Gemini API
